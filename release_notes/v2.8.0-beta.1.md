## v2.8.0-beta.1

Home Assistant **2026.9** compatibility release (tested against `home-assistant-frontend 20260826.7`).

### FIXED
- **Mode names were not rendered / the card could not resolve any label**: `getLabel()` read the
  translations from `hass.resources`, a map that no longer exists in the Home Assistant frontend.
  Translations are now resolved through `hass.localize()`.
- **`more-info` and `navigate` tap actions did nothing**: `hass-more-info` and `location-changed`
  were dispatched with `composed: true` but without `bubbles: true`, so they never reached the
  `home-assistant` element listening for them. Both events now bubble up to the app.
  The `navigate` action also keeps the Home Assistant history state instead of overwriting it with `null`.
- **Custom `target_temperature.change_action` received an undefined `climate_entity`**
  (`this.hass[this.config.entity]` → `this.hass.states[this.config.entity]`, upstream #165).
- **Icon buttons (toggle, dropdown, temperature up/down) were rendered in the new 48px default size**:
  `ha-icon-button` replaced `--mdc-icon-button-size` with `--ha-icon-button-size`.
- `--more-info` was applied to the card even when `tap_action: none` was configured, and the
  string form of `tap_action` (`tap_action: none`) was not normalized.

### ADDED
- **`action: perform-action`** support for `tap_action` (`perform_action`, `data`, `target`), the
  spelling introduced in Home Assistant 2024.8. `call-service`, `service` and `service_data` keep working.
- **`url_path`** support for the `url` tap action (`url` keeps working).
- HVAC mode, fan mode and HVAC action names are resolved with `hass.formatEntityState()` and
  `hass.formatEntityAttributeValue()` when the frontend provides them, so modes of integrations with
  their own translations are localized too. `hass.localize()` is used as the fallback.
- `CHANGELOG.md` covering the complete release history.
- Modern Home Assistant theme variables are preferred: `--state-icon-color`
  (falling back to `--paper-item-icon-color`).

### CHANGED
- Repository, CI and release links point to this fork, `hacs.json` and `info.md` updated.
- GitHub Actions modernized: `actions/checkout@v4`, `actions/setup-node@v4` (Node 20),
  `svenstaro/upload-release-action@2.9.0`, `$GITHUB_OUTPUT` instead of the removed `::set-output`
  command, an explicit `contents: write` permission, and tags containing a `-`
  (like `v2.8.0-beta.1`) are published as GitHub **pre-releases**.

### NOTE
- This is a pre-release. The changes were verified against the Home Assistant 2026.9 frontend
  sources and with automated checks, but not yet against real devices.
