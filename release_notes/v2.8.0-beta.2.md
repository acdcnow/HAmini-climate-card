## v2.8.0-beta.2

Repository rename + documentation refresh. The only difference in the built card compared to
`v2.8.0-beta.1` is the repository URL used by the card picker.

### CHANGED
- The GitHub repository was renamed **`acdcnow/HAmini-climate-card` → `acdcnow/mini-climate-card`**.
  GitHub redirects the old URLs. HACS installs to `www/community/mini-climate-card` from now on, so
  existing installs should remove the old `www/community/HAmini-climate-card` folder.
- The card picker `documentationURL` points at the new repository name — the only line of
  `mini-climate-card-bundle.js` that differs from `v2.8.0-beta.1`.
- `README.md`: badges, install/update/`wget`/clone URLs, the custom repository instructions and the
  notice now reference the new repository name and the current pre-release.
- `info.md` (the file HACS displays): the version badge includes pre-releases, the changelog link
  points at the release page, and the 2026.9 highlights are summarised.
- `package.json`: `repository`, `homepage` and `bugs` point at the new repository name.
- `CHANGELOG.md`: added this release.

### INCLUDED FROM v2.8.0-beta.1
- Home Assistant 2026.9 compatibility: `hass.localize()` instead of the removed `hass.resources`,
  `bubbles: true` for `hass-more-info`/`location-changed`/`ll-custom`, `hass.states[…]` lookup for
  `target_temperature.change_action`, `--ha-icon-button-size`, `--state-icon-color`.
- `action: perform-action` (`perform_action` / `data` / `target`) and `url_path` support next to the
  legacy `call-service`/`service`/`service_data`/`url` spellings.
- Mode names resolved with `hass.formatEntityState()` / `hass.formatEntityAttributeValue()`.

### NOTE
- Pre-release: enable *Show beta versions* in HACS to install it, or download the release asset.
