## v2.8.0

First stable release of this fork: full **Home Assistant 2026.9** compatibility, tested against
`home-assistant-frontend 20260826.7`. It consolidates the pre-releases `v2.8.0-beta.1` and
`v2.8.0-beta.2`; there is no functional change since `v2.8.0-beta.2`.

### FIXED
- **Mode names / labels were not resolved**: `getLabel()` read the translations from `hass.resources`,
  a map the Home Assistant frontend no longer provides. Translations now go through `hass.localize()`.
- **`more-info` and `navigate` tap actions did nothing**: `hass-more-info` and `location-changed` were
  dispatched with `composed: true` but without `bubbles: true`, so they never reached the
  `home-assistant` element that listens for them. `navigate` also keeps Home Assistant's history state now.
- **Custom `target_temperature.change_action` received an undefined `climate_entity`**
  (`this.hass[this.config.entity]` → `this.hass.states[this.config.entity]`).
- **Icon buttons (toggle, dropdowns, temperature up/down) rendered at the new 48 px default size**:
  `ha-icon-button` replaced `--mdc-icon-button-size` with `--ha-icon-button-size`.
- `--more-info` was applied even with `tap_action: none`, and a string `tap_action` was not normalized.

### ADDED
- **`action: perform-action`** support for `tap_action` (`perform_action`, `data`, `target`) — the
  spelling introduced in Home Assistant 2024.8. `call-service`, `service` and `service_data` keep working.
- **`url_path`** support for the `url` tap action (`url` keeps working).
- Mode names resolved with `hass.formatEntityState()` / `hass.formatEntityAttributeValue()` when the
  frontend provides them, so modes of integrations with their own translations are localized as well.
- `CHANGELOG.md`, a HACS install section in `info.md`, and the upstream release notes for v2.7.3/v2.7.4.

### CHANGED
- Repository renamed `HAmini-climate-card` → `mini-climate-card`; badges, install/update/clone URLs,
  `package.json` metadata and the card picker `documentationURL` updated.
- Modern theme variables are preferred (`--state-icon-color`) and mode labels use the current
  translation keys.
- GitHub Actions run on Node 24 action versions; tags containing `-` publish pre-releases, plain tags
  publish releases with the built bundle.
- `hacs.json`: `hide_default_branch` — HACS installs from releases instead of the default branch.

### NOTE
- Verified against the Home Assistant 2026.9 frontend sources and with automated checks; testing
  against real climate hardware is still up to you.
